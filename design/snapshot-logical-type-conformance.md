# Snapshot logical-type conformance

This packet closes the representative logical-type gaps left by
`snapshot-conformance-matrix.md`. Evidence counts only when the scan follows
the production boundary:

1. a public immutable `SharingRead` enters `read_arrow_stream()`;
2. R performs the Sharing request, NDJSON decoding, response validation,
   bounded action staging, and private synthetic-log preparation;
3. the existing narrow native bridge gives that log to Delta Kernel 0.22.0;
4. Delta Kernel produces the Arrow C Stream consumed by the R adapter.

The executable evidence is isolated in
`tests/testthat/test-snapshot-logical-types.R`. The package-owned fixture,
generator, provenance, and checksums live in
`tests/testthat/fixtures/delta/logical-types/`.

## Decision matrix

| Delta logical shape | Physical Arrow/Parquet shape | Result |
| --- | --- | --- |
| `decimal(18,4)` and nested `decimal(12,3)` | Arrow decimal128 at the declared precision and scale | Proven through projection, schema export, and materialized positive, negative, and null values. |
| `map<string,decimal(10,2)>` | Arrow map with non-null UTF-8 keys and decimal128 values | Proven for multiple entries, one entry, and a null map. |
| `timestamp` | Arrow `timestamp[us, UTC]` | Proven at top level and inside an array-of-struct field, including fractional microseconds. |
| `timestamp_ntz` | Arrow `timestamp[us]` without timezone metadata | Proven at top level and in a nested struct. The Arrow C schema remains timezone-free; the base-R data-frame adapter applies UTC as its stable POSIXct display timezone because POSIXct has no timezone-free logical type. |
| Name-mode column mapping | Physical names differ at every top-level and nested struct field | Proven across decimal, map, timestamp, struct, nested struct, and array-of-struct projection. Kernel restores all logical names. Existing focused evidence separately covers top-level ID-mode mapping. |
| `interval day to second` | No fixture column | Deliberately unsupported. Delta Kernel 0.22.0 rejects interval as an unsupported Delta table type while parsing the logical schema. The public path returns a redacted `delta_sharing_native_error`, closes the transport once, and removes the staged/synthetic state. |

## Scope decision

No production R, Rust, CI, or capability-advertisement change is required.
Decimal, map, both Delta timestamp kinds, and deep name mapping already work
through the accepted R-owned planning and Delta-Kernel-owned scan boundary.
Interval support would require an upstream Kernel schema capability or an
explicit future architecture decision; it is not a reason to move additional
planning or materialization logic into Rust.
